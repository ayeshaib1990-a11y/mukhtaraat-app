# مَخْتَارَاتٌ مِن أَدَبِ الْعَرَبِ (Mukhtaraat Arabic Reader)
### مستند ادبی و صرفی پلیٹ فارم (برائے طلبۂ مدارس و جامعات — پاکستان و برصغیر)

---

## 📌 الف مقصورہ کا مستند پاکستانی اسلوب (Pakistani Orthography for Alif Maqsura)

تمام اسباق میں **برصغیر (پاکستان و ہندوستان)** کے مستند رسم الخط اور املا کی مکمل پابندی لازمی ہے:

1. **کھڑی زبر کی براہِ راست تنصیب (Direct Dagger Alif Placement):**
   * الفِ مقصورہ کی صورت میں کھڑی زبر (`ٰ` / `\u0670`) ہمیشہ **براہِ راست حرفِ اصلی (consonant) پر** آتی ہے۔
   * اس حرف پر عام زبر (fatha) لگانا غیر ضروری اور خلافِ رسم الخط ہے۔
   * بعد والی یاء (`ى`) خاموش کرسی (seat) کا کام دیتی ہے۔

2. **معیاری امثلہ (Standard Examples):**
   * **`إِلٰى`** — لام پر کھڑی زبر `لٰ` + `ى` (نہ کہ `إِلَىٰ`)
   * **`عَلٰى`** — لام پر کھڑی زبر `لٰ` + `ى` (نہ کہ `عَلَىٰ`)
   * **`نَخْشٰى`** — شین پر کھڑی زبر `شٰ` + `ى` (شین پر زبر غیر ضروری ہے، نہ کہ `نَخْشَىٰ`)
   * **`يَسْعٰى`** — عین پر کھڑی زبر `عٰ` + `ى` (نہ کہ `يَسْعَىٰ`)
   * **`حَتّٰى`** — تاء پر تشدید و کھڑی زبر `تّٰ` + `ى` (نہ کہ `حَتَّىٰ`)
   * **`الْعُرٰى`** — راء پر کھڑی زبر `رٰ` + `ى`
   * **`التَّقْوٰى`** — واؤ پر کھڑی زبر `وٰ` + `ى`
   * **`الْهُدٰى`** — دال پر کھڑی زبر `دٰ` + `ى`
   * **`السُّفْلٰى`** — لام پر کھڑی زبر `لٰ` + `ى`
   * **`أَعْمٰى` / `الْعَمٰى` / `عَمٰى`** — میم پر کھڑی زبر `مٰ` + `ى`
   * **`وَكَفٰى`** — فاء پر کھڑی زبر `فٰ` + `ى`
   * **`وَأَلْهٰى`** — ہاء پر کھڑی زبر `هٰ` + `ى`
   * **`الْغِنٰى` / `غِنٰى`** — نون پر کھڑی زبر `نٰ` + `ى`
   * **`جُثٰى`** — ثاء پر کھڑی زبر `ثٰ` + `ى`
   * **`هٰذَا` / `ذٰلِكَ`** — ہاء اور ذال پر کھڑی زبر
