۱۔ جہاں فیصلہ درکار ہے

Open rulings — a decision is wanted on each

1. The triliteral بَاب نمونہ — ضَرَبَ or سَمِعَ?

The earlier rule ("every three-letter verb uses نَصَرَ") is withdrawn; the user's own approved تَعْرِفُ is باب ضَرَبَ يَضْرِبُ, so the نمونہ follows the word's own معرب. But ضَرَبَ and سَمِعَ are the same وزن (فَعِلَ / يَفْعَلُ), and the app already uses both names. Which نمونہ should be written for that pair?

2. شُشّ for the اِسْتِفْعَال forms

The user's catalogue heads all ten derived أبواب as ثلاثی مزید فیہ, and اسْتَكَانُوا was approved as such. An earlier guide however listed form X (مَعْصِيَة, أَحْفَظ, اِعْرِضْ) as ثلاثی مجرد. Which applies?

3. بحث for a verb — no مجزوم / منصوب

New ruling: a verb's بحث carries the گردان alone, so فعل مضارع معروف (مجزوم) should read فعل مضارع معروف. Please confirm, because the approved تَذْهَبُ reference still carries the bracket and is at present a known deviation. A noun's منصوب/مجرور is unaffected — that is case, not mood.

4. ابْتُلِيَ — the مادہ looks wrong

Both copies give مادہ ب - ل - و; the expected root is ب - ت - ل.

5. صِّیغَہ for an attached pronoun

Still unsettled for a handful of entries (pilot ids 6 and 20): should the pronoun be folded into صِّیغہ, e.g. مفرد مذکر غائب (اسم + ضمیر مضاف)?

6. Pilot id 3 ائْتِ

The form is disputed (imperative of اِتَّى is اِتْ) and the مادہ is recorded أ - ت - ي where the standard root is و - ت - ي.
